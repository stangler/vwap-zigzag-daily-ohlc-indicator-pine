# 統合版：VWAP & Zig Zag & 単日四本値

TradingView 用 Pine Script v6 インジケーターです。VWAP・Zig Zag・単日四本値・前日四本値・**前日大引けVWAP**・移動平均線を1つのスクリプトに統合しています。

---

## 機能一覧

| 機能 | 概要 |
|------|------|
| **VWAP** | 当日始まりの出来高加重平均価格。標準偏差バンド付き |
| **移動平均線** | 5本・20本の単純移動平均線 |
| **単日四本値** | 指定した日付の始値・高値・安値・終値をチャート上に表示 |
| **前日四本値** | 前営業日の始値・高値・安値・終値を水平ラインで表示 |
| **前日大引けVWAP** | 前営業日の最終バー（例：15:30）時点のVWAPを水平ラインで翌日に表示 |
| **Zig Zag++** | MT4 の ZigZag 互換の Zig Zag。HH / LH / HL / LL ラベルとアラート付き |

## Zig Zag の見方

### パラメータの意味
MT4 の ZigZag と同じ考え方です。

- **Depth**：頂点を決めるときに見るバー数。「前後 Depth 本の中で最も高い（低い）バーだけを頂点にする」イメージです。
- **Deviation**：直前の頂点から反対方向へ、最低これだけ値が動かないと新しい頂点にしない、という最小の値幅です。小さな揺れを無視するフィルターとして働きます。
- **Backstep**：高値と安値の頂点の間に最低何本のバーを空けるか。最小値は 2 です。

### 細かく・多く表示するには
効果が大きい順に次のとおりです。

1. **Depth を小さくする**（12 → 5 前後。最小は 1）。最も効果が大きい設定です。
2. **Deviation を小さくする**（5 → 1〜3）。小さな値幅の反転も頂点として拾います。
3. **Backstep** は最小値の 2 のままにします。

| 表示 | Depth | Deviation | Backstep |
|------|-------|-----------|----------|
| 初期値 | 12 | 5 | 2 |
| やや細かい | 8 | 3 | 2 |
| 細かい（5分足のデイトレ向け） | 5 | 2 | 2 |
| 最も細かい | 3 | 1 | 2 |

> 細かくしすぎるとノイズまで頂点になり、線が増えすぎます。まず Depth だけを変えて確認してください。大きな波だけを見たいときは、Depth と Deviation を大きくします。
> 頂点は確定するまで動く（リペイントする）ことがあります。確定した頂点だけを表示したい場合は「リペイント」をオフにしてください。

### ラベル（HH / LH / HL / LL）の意味
頂点が、**1つ前の同じ種類の頂点（高値は高値、安値は安値）と比べて切り上がったか切り下がったか**を表します。

| ラベル | 読み | 意味 |
|--------|------|------|
| **HH** | Higher High | 高値の切り上げ |
| **LH** | Lower High | 高値の切り下げ |
| **HL** | Higher Low | 安値の切り上げ |
| **LL** | Lower Low | 安値の切り下げ |

- **上昇トレンド**：HH と HL が続く
- **下降トレンド**：LH と LL が続く
- **転換のサイン**：上昇中に LH / LL が出る、または下降中に HL / HH が出ると、勢いが変わった可能性があります。

アラート条件にも同じ4種類（New Higher High など）と、方向転換（Direction Changed / Bullish Direction / Bearish Direction）が用意されています。

- Pine Script v6

> 出来高データがない銘柄では `runtime.error` が発生します。

## 注意事項

- **単日四本値・前日四本値・前日大引けVWAP** は日足以上（日足・週足・月足）のチャートでは自動的に非表示になります。
- `max_lines_count=500`・`max_labels_count=500` を設定しています。長期間表示すると古いオブジェクトは自動削除されます。
- 前日四本値は `request.security` で日足データを取得しているため、リアルタイムバーでは確定値と異なる場合があります。
- 前日大引けVWAPは、日付切り替え時に **`vwapValue[1]`（前日最終バーのVWAP）** を確定値として採用します。
